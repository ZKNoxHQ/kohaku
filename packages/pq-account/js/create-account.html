Falcon-512 uses a WASM-compiled signer and is available in software mode only. Ledger support is not available for Falcon.

Signing Keys

ECDSA and ML-DSA-44 keys are derived via PQ-SLIP (BIP-39 + HMAC-SHA512)
Both ECDSA and ML-DSA keys are derived on the Ledger secure element via BIP32 path m/44'/60'/0'/0/0. No keys leave the device.
The deployment transaction will also be signed by the Ledger — no browser wallet needed.
